    Quick tips¶

    Textevo tries to guess what you want from what you select. These tips save a lot of clicks.

    Modifier keys¶

    Shortcut What it does
    Alt + click Add An exit: the keyframes go from 0 % to 100 %, with the easing mirrored.
    Alt + click Paste The first keyframe lands at the current time instead of the start of the layer.
    Alt + click apply (or Alt + double click a preset) Same for a preset: the first keyframe at the current time.
    Shift + click Presets Saves the Textevo of the selected layer as a preset, without opening the window.

    Let the selection do the work¶

    • Select a Textevo effect to work on it only, select the text layer to work on all its Textevo: Remove, Copy, Motion and Based on follow this rule.
    • Select several text layers to Add, Paste, apply a preset, switch 2D / 3D or change the Based on mode on all of them at once.
    • Select nothing and click Add, Motion or Paste, or apply a preset: Textevo creates a text layer for you.
    • Rename a Textevo without looking for its effect: select the text layer, it works if the layer has only one Textevo.

    Animate faster¶

    • An arrival and an exit on the same text: click Add at the start, then Alt + click Add at the end. Set the Transform values of each one, done.
    • An elastic title in one click: select nothing, click Motion > Elastic. You get a text layer with a Textevo whose keyframes are already set for the elastic (12 frames apart, see the settings).
    • Add an elastic to a plain text layer: select it and choose Motion > Elastic: it gets a Textevo ready to play.
    • Your favorite defaults: set the duration, the easing, the delay and the direction of a new Textevo in the settings, once and for all.
    • A wave through the text: Motion > Oscillation, then increase Phase per character.
    • Sync the words with a voice over: Based on > Words, then Motion > Markers: one marker per word is added, move each marker under its word in the audio.
    • Another random order: with the Random direction, change the Random Seed.

    Timing¶

    • The Delay is in frames between two letters, words or lines. Changing the Based on mode with "Auto adapt the delay" keeps about the same total duration.
    • Closer keyframes give a stronger elastic or bounce.
    • If an elastic or a bounce doesn't show, the keyframes are eased on arrival: let Textevo optimize them (see Eased keyframes). Check "Don't ask again" if you always want the same answer.

    Presets¶

    • Presets keep your whole look: add a wiggly selector, a fill color or a stroke to the Textevo text animator, they are saved with the preset. Select the whole layer and choose Save all to also save its drop shadow, glow...
    • Apply a preset on many texts at once: select all the text layers, then double click the preset.
    • Dock your presets: install textevo presets.jsxbin and dock the presets manager next to your timeline, your presets are always one double click away (see Dockable presets panel).
    • Find a preset fast: type a part of its name in the search field, or filter the list by Based on (letters, words, lines) and Motion (elastic, bounce...).
    • Share a preset: it is a .json file in your presets folder (Settings > Open). Send it, the other person copies it in their presets folder and clicks refresh.
    • Old presets landing far after the text? Accept the update when the presets window opens, or apply them with Alt + click.

    Keep things clean¶

    • Always Remove and Rename a Textevo with the panel buttons: they handle the effect and its text animator together.
    • Switching 2D / 3D, renaming or changing the motion of a Textevo keeps everything you added to its text animator.
